# Правила названий n8n

## Названия модулей

Формат:

`MXX - Краткое название`

Правила:

- Использовать английскую букву `M`.
- Номер модуля записывать двумя цифрами.
- После номера ставить пробел, дефис и ещё один пробел.
- Название должно кратко описывать назначение модуля.

Примеры:

- `M01 - Основы n8n`
- `M02 - Работа с данными`
- `M06 - Резервное копирование`

## Названия workflow

Название должно отражать действие и результат сценария.

Примеры:

- `Form to Telegram`
- `Create Payment Link`
- `Update Order Status`
- `Daily n8n Backup`

## Названия файлов

Использовать строчные английские буквы и дефисы вместо пробелов.

Примеры:

- `form-to-telegram.json`
- `create-payment-link.json`
- `daily-n8n-backup.json`
